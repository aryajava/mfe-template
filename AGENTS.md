# Agent Guidelines for mfe-template

This repository contains a micro-frontend (MFE) template monorepo managed with pnpm workspaces.

## Agent skills

### Issue tracker

GitHub Issues (`aryajava/mfe-template`). See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical five-role triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout with root `CONTEXT-MAP.md`. See `docs/agents/domain.md`.
